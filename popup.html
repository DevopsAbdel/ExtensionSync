Web Store Proxy (metadata)

To show publisher & ratings, the Chrome Web Store must be fetched through a CORS proxy (its own pages block direct access). Leave empty to disable this feature.

Default: http://localhost:8123 (run node tools/cors-proxy-node.js 8123). For a public proxy, use HTTPS.
